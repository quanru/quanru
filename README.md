### 🤖 [Midscene.js](https://midscenejs.com)

<p align="left"><a href="https://github.com/web-infra-dev/midscene"><img src="https://midscenejs.com/midscene_with_text_light.png" alt="Midscene Banner" width="100" /></a></p>

**AI-Powered UI Automation Framework.**

Midscene.js makes UI automation stable, easy to debug, and friendly to maintain using Multi-modal AI.

*   **Natural Language Interaction**: Control **Playwright**, **Puppeteer**, and **Android** devices using simple natural language prompts (e.g., "Tweet 'Hello World'").
*   **Visualization**: Provides visualized reports with an integrated Playground for debugging and tuning prompts.
*   **Flexible Usage**: Supports YAML scripts for codeless automation and integrates seamlessly via JavaScript SDK.
