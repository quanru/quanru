## 🚀 Featured Projects

### 🤖 [Midscene](https://midscenejs.com)

<p align="left"><a href="https://github.com/web-infra-dev/midscene"><img src="https://midscenejs.com/midscene_with_text_light.png" alt="Midscene Banner" width="120" /></a></p>

**AI-powered UI automation that stays debuggable.**

Midscene makes UI automation stable, easy to debug, and friendly to maintain using multimodal AI.

* **Natural Language Automation**: Control Playwright, Puppeteer, and Android devices with prompts.
* **Visualization**: Visualized reports make prompt tuning and failure analysis inspectable.
* **Flexible Usage**: Supports JavaScript SDK and codeless YAML automation flows.

### 📱 [Vibelet](https://vibelet.icu)

**AI coding from your phone.**

Vibelet is a mobile remote for Claude and Codex sessions.

* **Remote Control**: Control Claude and Codex side by side, each agent in its own workspace.
* **Fast Pairing**: Pair instantly with QR scanning, with remote-ready and LAN-only modes.
* **Mobile Workflow**: Supports image sharing, file browsing, downloads, approvals, and session resume.

### 📝 [Aino](https://aino.md)

**AI native note-taking app.**

Aino combines AI chat, Markdown editing, calendar planning, tasks, Pomodoro, habits, and life reviews into one native workspace.

* **AI Chat**: Supports multi-model AI chat with note context, date ranges, and prompt templates.
* **Daily Execution**: Includes Markdown editing, calendar views, task inbox, habits, and periodic reviews.
* **PKM Workflow**: Brings LifeOS-style knowledge management into a dedicated native app.

### 🧠 [LifeOS](https://lifeos.vip)

<p align="left"><a href="https://github.com/quanru/obsidian-example-lifeos"><img src="https://lifeos.vip/rspress-light-logo.png" alt="LifeOS Banner" width="50" /></a></p>

**A complete personal knowledge management system for Obsidian.**

LifeOS is designed to bring structure to life and work through repeatable PKM workflows.

* **Methodology**: Implements PARA and periodic notes from daily to yearly.
* **Awards**: Winner of [Obsidian Gem Awards 2024](https://obsidian.md/blog/2024-goty-winners/) Bronze in Best Template Category.
* **Ecosystem**: Uses Dataview, Templater, templates, reviews, plans, and reflection rituals.

### 📅 [Calendar Pro](https://lifeos.vip/zh/plugin/calendar/calendar-pro.html)

**A serious planning layer for Obsidian.**

Calendar Pro turns Obsidian tasks into a schedulable calendar system.

* **Views**: Supports month, week, day, agenda, kanban, timeline, and four-quadrant planning views.
* **Task Planning**: Move tasks between sidebars, dates, time blocks, priorities, tags, and timelines.
* **Calendar Sync**: Connects remote calendars with ICS and CalDAV, including iCloud and Google Calendar.

### 💬 [DeepAsk](http://deepask.vip)

**AI chat plugin for Obsidian.**

DeepAsk brings context-aware conversations to Obsidian.

* **Vault Context**: Chat with open notes, webpages, multiple files, and time-scoped context.
* **Model Support**: Supports GPT, Gemini, DeepSeek, Qwen, Kimi, Claude, Ollama, and custom models.
* **Plugin Workflow**: Adds poster generation, Chrome integration, prompt selection, tags, and MCP access.
