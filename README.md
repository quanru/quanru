### 🔎 [DeepAsk](http://deepask.vip)

<p align="left"><a href="http://deepask.vip"><img src="https://lifeos.vip/about-assets/deepask-icon.svg" alt="DeepAsk plugin icon" width="72" /></a></p>

**AI chat across Obsidian and Chrome.**

DeepAsk has two parallel surfaces: [DeepAsk for Obsidian](http://deepask.vip) brings vault-aware AI chat into Obsidian, while [DeepAsk for Chrome](https://chromewebstore.google.com/detail/deepask-ai/abhoenehflglmgbohaibihggedfcpcep) combines browser context with Obsidian context by calling the context exposed by the Obsidian plugin.

* **DeepAsk for Obsidian**: Chat with notes, tags, files, and time-scoped vault context.
* **DeepAsk for Chrome**: Combine browser context with Obsidian context for web tasks.
* **Shared Context**: The Chrome extension can call the Obsidian context exposed by the plugin, so web tasks can use vault knowledge.

### 📲 [Remosidian](https://remosidian.pages.dev)

<p align="left"><a href="https://remosidian.pages.dev"><img src="https://lifeos.vip/about-assets/remosidian-icon.png" alt="Remosidian app icon" width="72" /></a></p>

**Your phone is a remote, not a second vault.**

Remosidian pairs a phone with a host running on your own computer so you can browse files, search notes, capture ideas, and ask local AI about your Obsidian vault while the vault stays on the host machine.

* **Local AI**: Ask from your phone while Claude or Codex reads vault context on the paired host.
* **Remote Notes**: Open folders, read Markdown, search notes, and capture ideas without syncing the whole vault elsewhere.
* **Flexible Host**: Uses a CLI host or private Obsidian plugin host with QR pairing, LAN, relay, or stable-host setup.

### 🎙️ [Doubao Say](https://github.com/quanru/doubao-say)

<p align="left"><a href="https://github.com/quanru/doubao-say"><img src="https://lifeos.vip/about-assets/doubao-say-icon.svg" alt="Doubao Say app icon" width="72" /></a></p>

**Voice input built for Linux, Wayland, and Omarchy.**

Doubao Say is an open-source GTK4 voice-input app powered by Doubao cloud recognition. Press a global shortcut, speak with live captions, optionally polish the transcript with an OpenAI-compatible model, and paste the final text into the active app.

* **Natural Input Flow**: Supports tap-to-toggle, hold-to-talk, live captions, and double-tap Enter.
* **Optional AI Polish**: Cleans up filler words, punctuation, and structure while preserving the speaker's meaning.
* **Omarchy Ready**: Ships as a standalone Linux app and an optional Omarchy plugin, with semantic UI checks powered by Midscene in a real VM.
* **Open Source**: Available on [GitHub](https://github.com/quanru/doubao-say) under the MIT license.
